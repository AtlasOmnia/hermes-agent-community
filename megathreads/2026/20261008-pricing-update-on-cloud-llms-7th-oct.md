# Pricing update on cloud LLMs (7th Oct)

**Posted by u/Larelle on 2026-10-08 · 8 points (100% upvoted) · 11 comments**

I loved Space Bunny, even more than Hy3.  With that gone, free/super cheap models are largely non-existent.  If you see better prices on the other providers, please add below.
GPT-6 Luna is probably the best cheap, strong model. It's worse than the 5.6 models but cheaper, even on Max, which is recommended.
GLM 5.3 Flash is now 12¢/M input (down from its $0.15 list price).
DeepSeek V4.1 Flash is now 11¢/M input, so it's no longer the 4¢/M it was previously.  There is a DS 4 Flash latest at $0.02/1M.  It's likely 0423 at that price.  This needs testing if no-one has already.
All prices are current on Nous:
https://portal.nousresearch.com/models
