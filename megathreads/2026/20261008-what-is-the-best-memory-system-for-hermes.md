# What is the best memory system for Hermes?

**Posted by u/matteoianni on 2026-10-08 · 17 points (72% upvoted) · 72 comments**

I want to create a new type of benchmark that measures the ability of an agent to stay coherent across sessions and connect dots organically by itself. No benchmark does that. They all either measure agent raw abilities in segregated sessions or measure memory in chat format (and in most cases with direct retrieval prompts, which is not what I’m after - I want the agent to know without me telling it what to look for).
To test Hermes Agent I need the best memory systems out there.
The benchmark will use the harness headless with a sequence of prompts that mix chatter, Terminal Bench tasks and Terminal Bench-like follow-ups tasks. It will do everything in sequence and will trigger many compactions.
For full transparency I made a competing harness with this long term coherence at its foundation. I want to build an honest and objective benchmark to compare it to Hermes, Open Claw and others. To do so I need your help in finding the best set up to compare it to.
