# My problem with hermes: subagent model inherits instead of using its own

**Posted by u/pelatho on 2026-09-23 · 5 points (100% upvoted) · 6 comments**

I tried hermes, both the CLI and the desktop app. I initially really liked the desktop app, but it seems it doesn't want to do what I want.
The biggest gripe I have is that when one agent delegates it uses the parent model instead of that subagent's defined model.
Isn't the point of delegation at least in part to save tokens and increase speed by way of delegating simpler smaller scoped tasks to faster/cheaper agents?
I also don't quite like that I can't clear the bot chat. Sometimes I might just want to do that, even if it's supposed to be persistent etc.
