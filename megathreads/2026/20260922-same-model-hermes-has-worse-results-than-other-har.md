# Same model - Hermes has worse results than other harnesses

**Posted by u/ManyMinute962 on 2026-09-22 · 40 points (84% upvoted) · 41 comments**

In the recent weeks, I've been testing Hermes vs my personal Codex and corporate Claude harnesses, using the same model. And Hermes results were not great.
I've been running exactly the same prompt, having the same MCP tools connected, and using the same model (e.g. GPT-5.6 Terra) in both Codex and Hermes.
I've noticed that in vast majority of cases, Hermes is so much less powerful. It could not even handle the simplest cases that you expect modern agents to crack.
For example, asked to find an old email in gmail from a company and a person from a specific timeframe. Company name had a typo.
Hermes: Tries to find it, then says that no such email exist (as there was a typo). After I fix the typo and start the query again, still pulled another email from another date.
Codex: Tried finding the email, could not due to the typo. By itself, successfully found the person, understood from the context of other emails that there was a typo, searched for the company name correctly, successfully found the email.
Does anyone else have the same experience? Were you able to fix it?
