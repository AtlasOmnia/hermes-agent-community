# What's the point of having both Profile and Bot mode in Hermes?

**Posted by u/marunaka on 2026-10-15 · 21 points (100% upvoted) · 16 comments**

​I’m new to Hermes and using the desktop app. I don't understand why the Sessions tab exists, the one where you select a profile to start a session and can switch profiles whenever you want. Meanwhile, in the Bot tab, you can do the exact same thing by picking a bot to chat with.
​I understand the conceptual difference between a bot and a profile: a bot is like a concrete instance of a profile, where every bot belongs to a specific profile, but a profile doesn't always need a bot.
​My question is about real-world usage: In what scenarios would you chat with a profile directly vs. using bot mode? Doesn't keeping profile-based session chats around cause confusion? Why not just stick to bot mode exclusively (like Grokbot)?
I'd love to hear your best practices for using both modes. Once you start using Bot mode, do you still use Session chats under profiles at all? How do you personally use each mode in your daily workflow?
