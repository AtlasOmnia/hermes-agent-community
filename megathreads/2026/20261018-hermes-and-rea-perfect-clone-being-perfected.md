# Hermes and REA: perfect clone being perfected

**Posted by u/flairtestuser123 on 2026-10-18 · 100 points (100% upvoted) · 15 comments**

So I've been asking a SAAS product I pay about $500/yr for to do one simple thing: make a job I created in one year with a bunch of details be copyable so I don't have to build the exact same job next year.  For 3 years, they have done nothing on the software, let alone my request.
Finally had it, set up a Hermes agent with the REA skills and Opencode and gave it my login credentials.  Over the last couple days, it's built the entire SAAS into a local docker container and imported all my data.
Then I set it loose on the Android app, it did the same.  I now have an app that actually syncs properly instead of the buggy shit they never fixed.
I would have been perfectly happy continuing to pay for this program if they had put in my damn copy function (which would not have been hard at all, essentially pre-populate a new activity form with the old data so I can save it in the new year).  But for a tenth of the price of one year's subscription, they can go fuck themselves now.
I've also added about half a dozen nice-to-haves that I've wanted in the past, and anything else I come up with I can add in minutes.
REA is the SAAS killer.
