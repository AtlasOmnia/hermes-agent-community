# Is Mnemosyne still the pick for Hermes memory, and what do you use to manage it?

**Posted by u/anguishedturtle on 2026-10-01 · 35 points (92% upvoted) · 64 comments**

I've been running Hermes on a Mac mini with Mnemosyne as the memory provider for a few weeks. Writes are solid. Recall is the weak spot: like others here have said, the agent often reaches for session_search or built-in memory before it checks Mnemosyne.
Three questions:
Is Mnemosyne still the best option for Hermes, or have people moved to Honcho, Hindsight, or mem0? I saw the MemConflict comparison here where Mnemosyne came last on accuracy but used about 10x fewer tokens. Does that match what you see day to day?
What do you use to browse and clean up the memory store? I've found wysie/mnemosyne-dashboard and hermes-memory-ui. Is there anything that edits (supersede, expire, merge duplicates) rather than just reading?
Any other Mnemosyne apps or plugins worth knowing about? Consolidation watchdogs, exporters, graph views, anything.
Setup: macOS, current Hermes, Mnemosyne as the memory provider plugin.
