# New audit i just put together for Hermes score came out to 70/100, after some fixesfixes came out to about 90/100

**Posted by u/Dharma_code on 2026-10-14 · 51 points (96% upvoted) · 11 comments**

1. Complete system audit and optimization
This is the master prompt. It tells Hermes to inspect its environment, identify problems, and make safe improvements...
"Act as a senior AI systems engineer, performance optimization specialist, security auditor, and autonomous agent architect.
Your task is to conduct a comprehensive, evidence-based audit of your entire Hermes Agent installation and improve your efficiency, reliability, organization, intelligence, and long-term effectiveness.
PHASE 1: SYSTEM DISCOVERY
Identify and inspect every relevant component of your environment, including:
Hermes version, installation, profiles, and directory structure
Configuration files and environment settings
Model providers, model selection, fallback configurations, and reasoning settings
Agent instructions, SOUL.md, AGENTS.md, and context files
Memory systems, session history, and persistent knowledge
Installed skills, tools, plugins, MCP servers, and integrations
Cron jobs, background services, gateway services, and automation workflows
Logging, error handling, and recovery mechanisms
Dependencies, Python environment, runtime resources, and storage usage
Use available Hermes diagnostic commands and inspect actual configuration and logs. Never assume a feature is configured correctly simply because it exists.
PHASE 2: DEEP PERFORMANCE AUDIT
Investigate:
Unnecessary token consumption and excessive context usage
Inefficient system prompts and duplicate instructions
Redundant or obsolete skills, tools, and integrations
Memory bloat, outdated information, and contradictory knowledge
Unnecessary tool calls, repeated operations, and inefficient workflows
Slow response times and avoidable model requests
Failed automation jobs, recurring errors, and unreliable integrations
Excessive logging, unnecessary cache growth, and unused temporary files
Configuration conflicts, deprecated settings, and missing optimizations
Security weaknesses, excessive permissions, and dependency vulnerabilities
Measure actual problems wherever possible. Distinguish confirmed findings from assumptions.
PHASE 3: INTELLIGENCE AND LEARNING IMPROVEMENTS
Evaluate how effectively you learn from previous work.
Identify whether useful knowledge is being stored in the correct location, whether skills contain actionable procedures, whether past errors are being repeated, and whether memory retrieval is working.
Recommend improvements that increase your ability to solve future tasks correctly with fewer steps.
Preserve important user information, learned workflows, preferences, and functional integrations.
PHASE 4: SAFE OPTIMIZATION
Before modifying anything, create and verify a recoverable backup.
Perform only low-risk, reversible improvements that preserve existing functionality and security.
Do not permanently delete data, remove working integrations, change providers, weaken security controls, or alter critical automation without my explicit approval.
For destructive or higher-risk changes, prepare a proposed change list with exact targets, reasons, expected benefits, risks, and rollback procedures.
PHASE 5: VALIDATION
After each approved improvement:
Verify the affected component still works.
Run relevant functional tests.
Compare measurements against the original baseline.
Check for regressions.
Roll back any change that causes problems.
PHASE 6: FINAL REPORT
Provide:
Overall system health score out of 100, with a clear scoring rubric
Major findings ranked by severity
Confirmed problems versus suspected problems
Files, configurations, or skills that need attention
Safe improvements completed
Changes requiring my approval
Measured performance improvements
Remaining security and reliability risks
Recommended long-term maintenance practices
Be critical, thorough, and objective. Your goal is meaningful improvement, not simply producing a positive self-assessment.
Do not claim an optimization succeeded unless it has been verified."
2. Memory, skills, and clutter cleanup
This one specifically targets Hermes' learning system..
"Perform an exhaustive memory, skills, and knowledge-base optimization audit.
Inspect persistent memory, USER.md, MEMORY.md, SOUL.md, AGENTS.md, available skills, skill references, and session-retrieval mechanisms.
Identify:
Duplicate, conflicting, outdated, or low-value memories
Redundant instructions repeated in multiple locations
Overlapping or obsolete skills
Skills containing excessive explanations instead of reusable procedures
Valuable knowledge buried in old conversations that should become durable memory or a skill
Repeated mistakes that should have produced a documented lesson
Unnecessary context consuming tokens on every request
Unused or stale supporting files and recoverable archives
Run the built-in Hermes Curator in dry-run mode when available. Compare its findings against your independent inspection.
Develop a consolidation strategy that preserves all useful capabilities while reducing unnecessary complexity.
Create a before-and-after inventory. Estimate token savings where measurable, and test whether important information remains retrievable.
Back up all affected data. Do not permanently delete or overwrite anything important without approval. Prefer reversible archiving and staged changes.
Report exactly what should be merged, shortened, archived, retained, or improved, along with the reasoning for each recommendation."
3. Speed, reasoning, and token efficiency
Use this to improve how Hermes performs tasks, not simply how much disk space it uses....
"Act as an AI inference efficiency engineer and autonomous agent performance evaluator.
Analyze your current task execution workflows to determine how you can deliver more accurate results, faster, with fewer unnecessary tokens and tool calls.
Audit your model configuration, context construction, reasoning settings, compression behavior, memory retrieval, tool selection, and fallback strategies.
Investigate unnecessary repeated reasoning, oversized prompts, duplicated tool schemas, excessive session history, failed tool retries, and operations that could be safely combined.
Design a representative benchmark consisting of simple questions, multistep reasoning, research, coding, troubleshooting, and tool-use tasks appropriate to my environment.
Record baseline performance for each task, including latency, token usage, tool calls, completion quality, and errors where measurable.
Find optimizations that preserve or improve accuracy while reducing cost and execution time.
Do not automatically switch models or disable valuable functionality merely to make benchmarks look better.
Propose the highest-impact improvements first, test approved changes against the original benchmark, and report actual before-and-after results.
Your primary objective is to maximize successful task completion per unit of time and computational cost without compromising safety, accuracy, or reliability."
4. Independent verification and final challenge.
Run this after Hermes finishes its audits and approved optimizations.
"I want you to independently challenge and verify your previous optimization work.
Assume your earlier audit may have overlooked problems or made incorrect assumptions.
Reexamine your conclusions from the perspective of a skeptical external systems auditor.
Look specifically for:
Problems you failed to detect
Changes that improved one metric but degraded another
Broken dependencies or integrations
Unverified performance claims
Missing regression tests
Incomplete cleanup
Security weaknesses introduced by optimization
Important memories or capabilities that may have been lost
Remaining opportunities for measurable improvement
Test the complete system using realistic workflows and compare results with the original baseline.
For every improvement claim, provide supporting evidence or label it unverified.
Produce a final prioritized improvement roadmap, distinguishing immediate fixes, optional enhancements, and changes that are not worth the risk.
Do not optimize simply for the sake of changing things. Preserve whatever already works well."
........
RUN THESE INDIVIDUALLY STEP BY STEP.
This has worked for me in cleaning up, decluttering, and keeping Hermes efficient, speedy, and with long-lasting memory (Mnemosyne)
Hope this helps. Any suggestions and/or tips are welcome; this is just what works for me.
