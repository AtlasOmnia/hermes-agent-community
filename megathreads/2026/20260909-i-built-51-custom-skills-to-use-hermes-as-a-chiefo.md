# I built 51 custom skills to use Hermes as a chief-of-staff. Here is the full catalog

**Posted by u/NecessaryYak8 on 2026-09-09 · 9 points (68% upvoted) · 5 comments**

I've been using Hermes Agent for months. Not as a chatbot, but as a chief-of-staff. I say what needs to be done, it figures out the best way, validates with me, and gets it done.
The default skills that ship with Hermes are useful but generic. I wanted skills that match my actual workflow. So I built 51 of them.
I organize everything around 4 pillars (WINS: Wealth, Insights, Network, Self). Each pillar has its own set of skills.
Wealth (14 skills):
Stock screening using S-curve analysis
Portfolio tracking and quarterly reviews
Screener.in data extraction and ratio calculation
GST invoice generation
Expense tracking
Insights (23 skills):
No-ai-slop editor (strips AI patterns from drafts)
YouTube transcript extraction into wiki
Blog-to-social conversion (one post → LinkedIn, tweet, thread)
Editorial diagram generation (27 types)
Writing corpus analysis
Network (3 skills):
LinkedIn post drafting from blog content
Email triage
Social media pipeline management
Self (15 skills):
Health data analysis from Amazfit watch
Book compilation to PDF via WeasyPrint
Weekly reviews and decision logging
Hermes config audits
How it works:
Each skill is a SKILL.md file. Markdown with YAML frontmatter. The agent reads it and follows the instructions. No code, no API calls, no frameworks. Just structured prompts.
I published the full catalog at
skills.jjude.com
. Every skill has a detail page showing what it does and when to use it.
The real takeaway:
The power isn't the default skills. It's building your own. Look at what you do repeatedly. Write a skill for it. Train the agent to work the way you think, not the way someone else imagined you work.
If you're building custom agent skills, I'd like to see what you've built.
