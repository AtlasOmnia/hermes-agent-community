# Ways to share Hermes profile with family

**Posted by u/Routine-Example927 on 2026-10-18 · 16 points (100% upvoted) · 13 comments**

I have been using Hermes since early summer, gotten through few updates and in general have stable setup that I'm comfortable with (that is basically Hermes running on mini pc, that I access through nesquina webui / android app and occasionally on Tg).
Now it would be nice to allow using Hermes to other family member(s). The issue is that they are not technically inclined. They use open webui instance I setup on web and through Conduit app on the phone. It works well, no significant complaints were heard 😄
What I have thought about:
- nesquina webui / android app: too complex for them and to be honest quite buggy. it is the "best of the worst" that I've found for myself
- owui connected to hermes using oai API. well, I read reviews it basically only streams text by default, without getting tool calls, approvals or anything else
- channels, like connecting over ws or tg: similar to above, only compounded by the fact everything becomes one single conversation mess. I have tg setup and only use it for super ad-hoc things on the go
The magical solution in my head would be something like OWUI (expose a single prefoconfigured profile for the user, allow the user to have multiple sessions), but with richer interaction (the abovementioned visible tool calls, clarifications, sending files etc).
Why am I typing this with my non-AI fat fingers: anyone with similar needs? Did you solve this for yourself?
