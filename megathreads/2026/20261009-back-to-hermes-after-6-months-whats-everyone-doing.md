# Back to Hermes after 6 months, what’s everyone doing differently these days?

**Posted by u/psychonautowl on 2026-10-09 · 7 points (81% upvoted) · 24 comments**

Hey everyone!
I was running Hermes around 6 months ago, but my server broke down and I’ve been out of the loop since then.
I’m planning to set it up again, and rather than going back to my old setup, I’m curious to see how things have evolved and what everyone is doing with Hermes these days.
A few things I’m particularly interested in:
Memory:
What’s everyone using for long-term memory now? Any new approaches or improvements worth looking into?
Models:
What models are you running? Any good local models you’ve had success with? Are you mixing local and cloud models?
Jev:
What’s the current state of things here? Is anyone running open-source models locally for this, or experimenting with alternatives?
Learning from other agents:
With agents like Dot, Grok Bot, Muse, etc., has anyone borrowed interesting ideas or features from them and implemented them in Hermes?
Skills and self-improvement:
Are you letting Hermes build or improve its own skills? Anything interesting you’ve done to make it smarter over time?
Automation:
What proactive or autonomous workflows have you built that are actually useful day to day?
Optimizations:
Any tricks for reducing token usage, improving performance, managing context, or making the whole setup more reliable?
Use cases:
What are you actually using Hermes for these days? Any cool projects, integrations, or underrated features worth sharing?
Or maybe a question to summarize it all:
If you had to set up Hermes from scratch today, what would you do differently?
I figured this could also be a useful thread for anyone new to Hermes or returning after some time away, to get an idea of where things stand and what’s worth exploring.
Would love to hear what everyone’s been building!
