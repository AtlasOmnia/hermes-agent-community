# Hybrid models? Local for the brains, outsource to Claude/GPT/etc for coding?

**Posted by u/11ama_dev on 2026-09-19 · 7 points (100% upvoted) · 9 comments**

Currently running Hermes on my local server with qwen 3.8 27b w4a16 150k ctx on a single RTX 3090. Seeing the post earlier today about how coding harnesses are needed for quality work since Hermes is not the best, I've been setting up Pi on my machine. Thing is, while qwen is amazing for its size, it's still not nearly the best at coding, and shines more as a general reasoning model. And if I'm context isolating with Pi anyways, if I configure it correctly, I could use Claude with Pi and have no sensitive or personal data sent to it - would be just generic code. Any coding that would require it would be handled locally, and my local Hermes would be the brains. Has anyone done something like this before? How has it worked out for you?
