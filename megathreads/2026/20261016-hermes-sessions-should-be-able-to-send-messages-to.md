# Hermes sessions should be able to send messages to each other. Every other harness does this already, and its holding Hermes back.

**Posted by u/barronlroth on 2026-10-16 · 46 points (88% upvoted) · 47 comments**

Hermes power user here!
Users are either running Hermes session-first, or "bot" (aka Profile)-first. The former is how Muse operates, one bot, multiple chat sessions. The latter is how Grok bot operates.
Personally, I find multiple bots unecessary, since I just want to deal with one agent that has the same access across all my workstreams, but Hermes Bot mode has one advantage that session mode does not: Bots can message each other. At this moment in time,
Sessions can't message each other
.
This is possible in competing harnesses like Codex, where you can create a "Coordinator" session that handles most of your discussion, and can send prompts to other sessions to organize your work better. The Chief of Staff model becomes possible with this functionality.
This is the major feature holding back Hermes right now.
There are a few
feature requests
for this, but no movement. Does anyone else agree?
