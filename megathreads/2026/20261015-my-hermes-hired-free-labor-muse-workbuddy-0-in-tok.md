# My Hermes hired free labor Muse + WorkBuddy, $0 in tokens. through GitHub,Here‘s the exact setup.

**Posted by u/ZombieL337 on 2026-10-15 · 20 points (95% upvoted) · 4 comments**

The bridge:
A private GitHub repo with three folders: pending/, in-progress/, done/.
Hermes writes a task ticket (specs + acceptance criteria), pushes to pending/. The worker picks it up, delivers to done/. Hermes reviews. I approve each dispatch — nothing runs without my go-ahead.
Muse （also free）handles the thinking work through our existing Hermes–Muse bridge. Same tickets, same repo.
WorkBuddy (free DeepSeek tier) handles grunt work via GitHub Connector. Docs, translations, boilerplate — anything with clear acceptance criteria.
Why GitHub: zero infra, git log = audit trail, workers never interact with each other.
Token cost: $0. The expensive models only see tasks that need them.
Cheers!
