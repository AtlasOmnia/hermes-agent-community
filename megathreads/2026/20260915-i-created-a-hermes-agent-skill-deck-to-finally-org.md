# I created a Hermes Agent Skill Deck to finally organize my skill.md files in an easy to view app.

**Posted by u/dontforgetthef on 2026-09-15 · 86 points (95% upvoted) · 17 comments**

I created a Hermes Agent Skill App for myself to finally view and search my skills from a companion app.
This app syncs with all your real skills md files into a SQLite db, is built with a Python FastAPI backend, and is lightweight with a Tauri shell so it doesn't eat up your memory.
The rest is React / Vite / Tailwind for organizing the folders, searching, & producing those vivid neon colors. I also built a little terminal.
You can even pop open a new session right from the app.
