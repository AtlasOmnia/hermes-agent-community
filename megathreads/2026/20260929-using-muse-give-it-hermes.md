# Using Muse? Give it Hermes 😂

**Posted by u/Marmotbath on 2026-09-29 · 143 points (94% upvoted) · 44 comments**

I was dicking around with Muse last night and told it to create a terminal I can access on its VM, since it doesn't come with terminal access.
Once I got a terminal I realized I could install other harnesses to it's Ubuntu VM...so I gave it Codex and Hermes.
While I could use Muse to communicate with Hermes via the CLI, I figured this could be kind of a handy way to get a free VPS/VM to run Hermes or anything else for that matter. I don't really see the benefit of this other than letting Muse use other LLMs if you so desired, but it is kind of cool!
