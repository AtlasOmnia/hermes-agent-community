# Hot take: don't bother with "proper settings" if you are a noob

**Posted by u/Sharlei on 2026-10-17 · 39 points (83% upvoted) · 25 comments**

You do not need to set up memory system, auxiliary orchestration or different profiles. Just plug in a cheap model (deepseek is not so strong, doesnt matter i still use it) and do stuff. If you need to modify Hermes ask Hermes to do it.
Don't wait till you have time to set everything up properly. Hundreds die in "good or nothing" purgatory.
It will work suboptimal, but who cares. It's easy to burn out chasing the best setup.
Learn on the job.
PS: tinkering is useful and fun and i love doing it myself. Just don't mistake tree for a forest.
PPS: people exaggerate their efficiency and overengeneer stuff.
Honk
