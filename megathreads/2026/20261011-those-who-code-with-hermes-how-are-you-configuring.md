# Those who code with Hermes: how are you configuring your coding profile?

**Posted by u/flairtestuser123 on 2026-10-11 · 10 points (91% upvoted) · 7 comments**

I'm using a very default coding profile, I've done nothing to add tools that it didn't add itself or adjust the soul/agents.md.  I love using Hermes for coding because I can jump around between projects and it's computer-use is very good for deployment.  Also, I have Hindsight running to keep track of projects and it seems to allow me to jump right back in where I left off on old projects I pick up again later.
What I've noticed is that it defaults to test-driven-development, and while this does seem to give pretty good results, it takes for bloody ever to get anything done lately.  I was writing a flutter front-end that interfaces a CANbus sniffer to get data from my combine, and it's at the point that it's running almost 500 tests when I go to add a feature or change something.
How have you set up your coding profile, what do you give it for tools and how do you configure it to keep it on track and not going down a rabbithole of testing?
