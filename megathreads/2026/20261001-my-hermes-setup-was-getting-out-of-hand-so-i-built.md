# My Hermes setup was getting out of hand, so I built this..

**Posted by u/Fog2Focus on 2026-10-01 · 26 points (84% upvoted) · 18 comments**

I’ve been tinkering with something around Hermes for the last little while and thought I’d start sharing some of the progress here.
I’m calling it Project OS for now.
It started from a pretty simple problem: once I had Hermes working across several different projects, I found it increasingly difficult to keep track of what was happening where.
I wanted to be able to open a project and immediately understand:
What are we working on?
What has already been done?
What’s running?
What needs review?
Where are the relevant chats/files/tasks?
And if I disappear for a few days… where exactly did I leave off?
So I started experimenting with a more project-focused layer around my Hermes setup.
It’s gradually turned into something more interesting than I expected.
Right now I have an early Project OS dashboard working with separate project views, project-linked Kanban/tasks, chats, files, automations and a few other pieces I’m still experimenting with.
One of my biggest goals is persistence. I don’t want closing a browser, restarting something, or coming back days later to mean reconstructing what was happening.
There’s still a lot to build (and probably a lot I’ll change), but it’s finally starting to resemble the thing I had in my head.
I thought I’d start building it a little more publicly rather than only posting once everything is finished.
Would be particularly interested to hear from people running multiple projects through Hermes: what becomes annoying or difficult once your setup starts getting bigger?
