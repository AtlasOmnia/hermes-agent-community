# Made a little whale that shows when DeepSeek is half price

**Posted by u/inexternl on 2026-09-12 · 8 points (100% upvoted) · 5 comments**

Someone here said they ask their agent to only run jobs during DeepSeek's off-peak hours. I was doing that by hand and kept getting it wrong, so I built something. It sits in the bottom right of the Desktop status bar. Blue means tokens are half price right now, grey means full price, and the number is how long until the price changes.
Hover it and it tells you when the rate flips in your own timezone.
There is also a small tool so the agent can check before starting a long job. Asking "is now a cheap time to run this?" gets an answer instead of a guess.
Install, if you want it:
hermes://plugin/install?repo=aimagist/hermes-desktop-deepseek-offpeak-status
https://github.com/aimagist/hermes-desktop-deepseek-offpeak-status
