# New Mac Studio + Hermes Agent running Qwen 3.5 35B — Daily driver setup

**Posted by u/PoppaBear1950 on 2026-09-24 · 9 points (100% upvoted) · 7 comments**

Hermes running locally on my daily driver with Qwen 3.5 35B has been an absolute sweet spot for day-to-day chat, Obsidian vault management, and Git maintenance.
To keep RAM footprint manageable on the 64GB Mac Studio, I set up a 15-minute idle kill switch so it releases memory when not in use. Runs like a dream.
My only mild regret is not springing for the 128GB unified memory config, but at nearly $5k, that price jump is tough to swallow. Anyone else balancing model footprint and idle unload timers on Apple Silicon?
Hermes projects a $15 a month savings... I'll take that :)
