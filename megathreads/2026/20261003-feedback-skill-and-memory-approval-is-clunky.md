# Feedback: Skill and Memory approval is clunky

**Posted by u/Sgt_ZigZag on 2026-10-03 · 5 points (100% upvoted) · 5 comments**

If you have skill or memory auto write approval turned off, the user experience around the slash commands is really clunky right now.
I don't trust Hermes with skill or memory auto write turned on. Something you get working on a Monday will work until Wednesday and then break because a hallucination decided it knew better and will update the previously correct skill/memory.
Fine, just turn it off I said.
The slash commands to review pending skills and memory approvals is not ergonomic in the webui. First run, /memory pending, copy the ID from there, then use it in approve or reject. Hermes itself cannot do this for you. The interactive "pending" modal is not very useful. It shows you info which you can copy from then disappears. You can't approve or reject in the modal itself.
The desktop app can't do this either. It just says `/skills·/skills is managed from the desktop sidebar.` When you look in the capabilities sidebar for skills you can't approve or reject the skill changes themselves.
What am I doing wrong? What is the native experience for skill and memory management inclusive of the desktop app?
