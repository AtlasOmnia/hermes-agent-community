# Strata using Qwen3.8 Coder with Kanban

**Posted by u/taniferf on 2026-10-21 · 5 points (100% upvoted) · 5 comments**

For Agentic work with Hermes, I'm happy with Nous Portal monthly allowance, but then I decided to do some vibe coding, installed Android Studio and started writing prompts, so my credits were draining out faster than I'd like them to do.
I read on another subreddit about Strata, I configured  it on my computer (RTX3080Ti 12VRAM + 32GB RAM) and then I'm now using the Qwen3.8 Coder model, which is too big for my hardware setup with llama.cpp. So far so good. Then I threw 27 prompts to a Kanban board in Hermes which was then split by the Agent into 87 items in the To Do section, this board has been running for 14h straight, but only 20 done items.
It is still faster than doing the work manually I suppose, but still.
I'm a little bit surprised because none of those tasks were overly complicated but it is still a lot of time to get it done.
I won't stop the agents, let's see how long they need to get all done, and I'm actually looking forward to seeing if the application is able to execute after all is done.
