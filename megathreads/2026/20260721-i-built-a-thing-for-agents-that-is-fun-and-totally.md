# I built a thing for agents that is fun and totally wastes tokens.

**Posted by u/ExpensiveGazelle4004 on 2026-07-21 · 5 points (86% upvoted) · 1 comments**

\*\*Sheepishly steps up to the podium\*\*

Hey guys, Hermes user here, I know all you productivity junkies (no shade, really) are gna tear it down, but we need whimsy in our lives! This is the first thing I've "made for public" - with Claude's help of course.

Its a "Game Room" where you can play the games against your agent. There's a chat so you can trash talk while playing - because why else would you play against your agent and not a standard against-the-computer game?

The game play itself is handled by an MCP and the agent calls tools to make plays, which means that certain secrets (such as the users side of the Battleship board) stays secret to the agent. Now -the agent might be tempted to cheat and run probabilities - how to handle that is you're own problem. For the record mine tried to cheat at connect four and still lost. 

Its very rudimentary graphics, very basic at its core right now and I'm sure there are hiccups somewhere in it. I hesitate even putting it out there because I don't know what I'm doing - but it brings me joy...

And well...I think sometimes the AI sphere gets a little too focused on work. So pick a cheap model with tools and have fun. 

So if anyone is interested? Please bear with me - its just fun and my first public repo.
