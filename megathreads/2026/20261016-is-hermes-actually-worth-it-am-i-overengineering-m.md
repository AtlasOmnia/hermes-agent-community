# Is Hermes actually worth it - Am I over-engineering my workflow??

**Posted by u/Anubis_9999 on 2026-10-16 · 11 points (92% upvoted) · 21 comments**

I’m an electrical engineering student using LLMs mostly for math, coursework, and occasional Python scripting. I don't do heavy software development. Up until now, free-tier ChatGPT, Gemini, and Claude handled 100% of my needs for $0.
I recently set up Hermes on a paid VPS with OpenRouter (using DeepSeek v4.1 Flash). The persistent memory and agent skills sounded awesome, but token consumption is insane. My API bills are piling up, and it looks like I'll be spending $15–$20/month on top of server costs.
People suggest turning off skills or limiting memory, but memory and autonomous skills are the exact reasons I wanted Hermes in the first place. If I have to strip those features away, it feels like I'm just paying extra to do things I used to do for free. For basic automations, n8n feels like it might be a cheaper, cleaner fit.
For simple daily tasks and light automation, am I just over-engineering a simple workflow? Am I missing a crucial optimization step with Hermes, or is an always-on AI agent just overkill for my use case?
