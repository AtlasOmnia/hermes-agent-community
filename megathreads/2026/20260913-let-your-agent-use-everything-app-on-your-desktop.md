# Let your agent use Everything app on your desktop

**Posted by u/liga_r on 2026-09-13 · 24 points (90% upvoted) · 6 comments**

Hi to all fans of the Everything utility
I just wanted to let you know that it has a built-in HTTP server; you can access its settings via Tools -> Options... -> HTTP Server.
One of my biggest breakthroughs in improving the Hermes Agent Desktop was granting it access to Everything app via a skill; now it can see literally everything on my PC and instantly locate complex items - anywhere in the system - based simply on the filename.
This has significantly sped up tasks involving system interaction, file handling, debugging dumps, and much more
You can simply enable the HTTP server in Everything and provide the link to the program's official documentation, and the agent will create the skill automatically.
Alternatively, you can use my ready-made version that I've made for myself, which already includes all the instructions on how to properly format requests for Everything
https://github.com/ligofff/everything-whole-system-file-search-skill
