# Hermes feels mentally impaired since gpt-6

**Posted by u/After_Wasabi_5720 on 2026-09-27 · 13 points (93% upvoted) · 15 comments**

I was using got-5.6-Luna on xhigh before and Hermes felt very useful. It was able to build a workflow where it was reading tickers from a Trello board from columns assigned for him and draft that into a workable story for a development profile, creating a PR that got reviewed and forwarding the review commentsback to the development profile to get them fixed. It didn’t work flawless but I didn’t expect that from Luna. (There is more details to this which I will leave out for the sake of the context)
now gpt-6-Luna seems to suffer heavily with this workflow being built by the previous model (even on max reasoning). I thought that could all still be flaws put in by 5.6 Luna
A different example where it is really getting obvious at this very moment are pending memory writes. I’m not sure how common that is for others but I saw these messages more often lately that there is learning for the internal memory that I should approve if I find the time. With 5.6 Luna there have been 24 pending memories which I asked my agent to go through them with me because I didn’t want to bother typing the whole approvals command with the IDs. So Hermes went through them, categorized them, combined similar ones and went through quite well explained multiple choices questions with me. All nice and comfortable.
Today I wanted to do the same thing with 6 Luna. Nothing, no categorized, no deduplication no nothing. That’s something I could have lived with but after 2 or 3 question it just gave me questions like this „how should we treat 35b684d5?“ with the possible answer sounding like „approve“, „discard“, „type own answer“. To me replying that it would be great if he wouldn’t just throw ids at me and give me context on the decision all I got was „No answer received“.
For the first time since I set up Hermes agent it feels stupid. Even switching between free models every few messages in the early times didn’t make it feel that clueless about what it is doing.
I’m reading a lot about how gpt-6 isn’t performing well in
r/codex
but are other people experiencing the same with Hermes as well?
