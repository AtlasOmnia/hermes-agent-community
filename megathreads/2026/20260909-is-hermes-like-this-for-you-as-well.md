# Is Hermes Like This For You As Well?

**Posted by u/PeaceNowPorfavor on 2026-09-09 · 18 points (87% upvoted) · 34 comments**

I’m a power user of Claude, Codex, and Gemini. I run a marketing agency and multiple businesses, with many clients and assets to manage. I use AI daily to help organize it all.
For planning, brainstorming, and research, which make up a big part of my marketing work, Hermes has been awesome. I love how it gets to know me and turns what it learns into reusable skills. Within a week, it became my main AI tool.
But the bugs and setup friction are making it hard to rely on:
Sessions suddenly stop halfway through.
The desktop interface jumps around. Switching between profiles, bots, and sessions makes the interface and conversation scroll position jump all over the place.
Integrations take too many steps. Connecting tools through MCPs feels harder than with other AI apps. Google OAuth was especially frustrating. Even simple things seem to require extra setup.
Computer use with a cloud instance is difficult. I haven’t managed to get Hermes to control my device while keeping the main instance running in the cloud.
The desktop app asks me to log in EVERY DAY. This one drives me crazy.
Conversations stop when I close the desktop app, even though my instance is hosted in the cloud.
For context, I’m using the official Hermes Cloud hosting through Nous Portal, with my Codex subscription and GPT Astra 6. I am running the latest version of the desktop and Hermes.
I’ve asked Hermes to troubleshoot itself, and it has fixed a few things, but most of these issues remain. I don’t mind some initial setup, but I don’t want troubleshooting to become a regular part of using the software.
I like the results enough that I want to stick with it, but I’m considering GrokBot because it seems more streamlined and user-friendly.
Are you experiencing the same issues? If so, is Hermes still worth it because you’re comfortable with the technical setup and troubleshooting? Or has your experience been smoother, and I might be doing something wrong?
I want to get my company’s operations set up and need to settle on a system I can rely on. I’d appreciate hearing your experiences. Thanks!
