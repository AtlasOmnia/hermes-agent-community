# Non-developers but ai power users, what are you using Hermes Agent Desktop for?

**Posted by u/gjrre on 2026-10-11 · 20 points (100% upvoted) · 11 comments**

Just sharing to connect with other Hermes power users, semi-vibe coders, and enthusiasts here.
I use Hermes as an all-around agent, mostly for marketing automation, writing and creating documents, organizing things, and helping with research and to-do lists.
Lately, I've been exploring a few new ways to use it:
Reminders:
Offloading more quick task tracking.
Automated marketing assignments:
Using it more often now because it is cheaper to run with Deepseek v4.1 flash compared to Astra or Sol.
Profiles and bots:
Switching back and forth between profiles and the bots interface. Sometimes the bots interface feels more human and refreshing than swapping profiles.
Philosophical chats:
Having deeper conversations with Hermes. ChatGPT isn't the only smart AI that can hold a good conversation anymore.
A virtual daughter bot:
Created a dedicated bot to act as our virtual daughter (sounds a bit wild, I know). The idea is to have a repository for family memories and thoughts so we can eventually pass on a Hermes USB stick when our time comes.
The
goal
command:
Finding myself using this underrated command a lot more lately.
Things I wish Hermes Agent handled more smoothly:
Google Drive integration:
Constantly hitting OAuth prompts every time I want to edit a Google Doc or Sheet is frustrating, so I keep getting dragged back to local Word and Excel files.
Browser use:
It still feels a bit unpolished and confusing to navigate. ChatGPT handles this much better with simple click-and-mention behavior for Chrome.
Computer use:
Right now it relies heavily on AppleScript and struggles to control other apps directly.
What is your Hermes story?
(I still keep ChatGPT around for troubleshooting on my MacBook because it handles system control much more smoothly than Hermes.)
